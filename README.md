# Healthcare Claims Analytics Capstone

## Project Type
Academic Team Project | Baylor University

## Project Overview
Performed a comprehensive analysis of 115,000+ healthcare claims records to identify patterns, reimbursement trends, and cost-related insights that support healthcare business decision-making.

## Tools & Skills Used
- R Programming
- Data Cleaning
- Data Transformation
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization
- Healthcare Analytics

## Key Work Performed
- Cleaned and transformed healthcare claims data
- Handled missing values and outliers
- Performed skewness reduction using transformations
- Conducted visualization and trend analysis
- Evaluated provider types, pricing strategy, deductibles, claims bucket, and patient responsibility

## My Contribution
Collaborated on healthcare claims analysis, data preparation, visualization, statistical interpretation, and business insights generation.
